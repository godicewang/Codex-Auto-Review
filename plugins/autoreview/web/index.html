让当前任务接入

安装配置完成后，新任务会加载插件。继续使用原来的任务时，请打开 Codex 中的 AutoReview 插件页，将插件关闭再开启一次，让桌面宿主刷新配置。无需进入 CLI。

在 Codex 里打开 AutoReview

点击当前项目任务顶部的 AutoReview，即会连接并开启这个项目，无需填写路径。如果当前对话尚未刷新配置，切换项目或开启新对话；在本地环境设置中选择此项目的环境。
