## 已验证

- 真实临时 Git、HTTP/SSE、stdin/stdout 和子进程协议：只读副本、来源归因、Stop 后匹配 completed 才启动、继续执行撤销候选、完成查询取消与超时、队列传达与重试、项目/会话隔离、48,000 字符批次、6,000 字符报告上限、200 条背压、迁移、正常停止及磁盘回收。
- 真实子进程在成功、失败、取消后退出；忽略 SIGTERM 的 worker 和工具得到回收。并发启动 8 个客户端连接同一个服务，shutdown 之后进程、锁和临时目录正常释放。
- 安装器通过官方 hooks/list 和 config/batchWrite 自动登记本插件精确定义，不调整其他插件信任或整体策略。安装探针确认 6 个 hook enabled/trusted、6 个 MCP 工具 connected。
- 工具栏动作安装保留普通多行 TOML setup 脚本。项目名称、注释和脚本内容不被误判为同名动作；已存在的自定义动作、静态数组和不明确语法保持原样。
- 真实 Codex 内置浏览器中的隔离双项目面板：设置/手动审计弹窗显示并绑定原项目，并发项目切换不改变提交目标。测试使用独立服务和临时项目，不修改生产项目设置。
- 真实已登录审计模型检查一个受控缺陷：删除 reduce 初始值后，中文报告指出 total([]) 抛出 TypeError，定位准确并建议恢复 0。源文件和 Git index 不变；报告可通过传达协议交接；所有测试副本已回收。
- 真实 stdin/HTTP 在中文 UTF-8 字符内部拆块，等待消费者读完首块后再发下一块：完整保留中文和 emoji。非法 JSON 的响应及 hook 日志不含测试输入片段，字节上限和无效编码拒绝有回归覆盖。
- 真实面板脚本的 DOM 事件测试区分首次等待、失败与空队列；失败不会遮蔽其他待传达报告，后续成功不会继续显示旧失败。这部分最终状态检查不是浏览器渲染验收。
- 根目录别名下的真实补丁更新、新增和删除均能归因；仍拒绝仓库内部符号链接及越界文件。真实启用 code-mode 的 CLI 与模型验证：写入事件被归因，模型复述了仅存在于预置报告附加上下文的随机标记，报告获得 stdout 交接确认。此探针使用合成报告，不评价审计模型质量。
- 真实官方 App Server 加隔离本地模型端点的对照：安装器在外部进程安装/刷新后，旧会话 0 个事件且模型请求没有标记；新会话 2 个事件且包含标记；在旧会话所属宿主刷新后，该会话也收到 2 个事件且包含标记。该实验不调用真实模型，不操作 GUI，不复制认证。
- 接入帮助始终可见，核对配置绑定弹窗打开时的项目，且明确不代表 GUI 会话已刷新。插件页链接来自保存的安装来源并经过编码；HTTP 接口需要令牌和同源校验，不接受客户端指定目标 URL。
- 本次真实只读复核发现根目录别名初版会漏检“仓库内部链接指回根目录”。已通过真实文件系统复现并修复：从最外层根目录开始逐段检查，保留原始 cwd 与尚未验证的父路径组件。绝对路径、链接 cwd、新增/删除和 `back/../file` 均有回归；修复前放行、修复后拒绝。该复核是手动启动并通过 API 读取，报告保留待传达；不是 GUI 自动反馈记录。

## 证据不能外推的部分

审计模型冒烟测试使用模拟宿主生命周期。浏览器验证的是 AutoReview 面板，而不是操作 Codex 原生对话。当前长期 GUI 任务尚未观察到自动 hook、自动报告或模型实际收到注入；安装成功、真实 CLI 的 hook 成功，以及 stdout 交接确认均不能单独证明这条 GUI 链路。

因此尚不能给出真实项目审计的准确率、召回率、采纳率或 GUI 自动反馈延迟。单个受控缺陷的正确报告不代表完整代码库审计质量。正常退出和磁盘恢复测试也不等于已完成真实 OS 强杀下全部孤立工具的回收验收。

macOS 原生外壳已构建，显示决策矩阵与既有面板操作经过本地检查；Codex 主应用原生界面的最小化/Space 操作没有在本次实验中直接验收。Windows/Linux 桌面集成仍需实际平台验证。

## 复现

- `npm test`：执行本地自动测试，不调用真实审计模型。
- `npm run check`：检查源码、JSON 和插件结构。
- `node scripts/experiment-regressions.mjs`：固定协议、DOM 事件和打包回放；不是 GUI 注入测试。
- `node scripts/probe-service-lifecycle.mjs`：独立临时服务的真实并发启动与退出。
- `node scripts/probe-installed.mjs`：已安装插件的官方配置/MCP 能力探针，不启动审计模型。
- `node scripts/probe-session-loading.mjs --external-reload`：真实 App Server 加本地模拟模型，复现外部配置刷新与同宿主刷新差异。
- `node scripts/probe-hook-transport.mjs`：真实 CLI 与模型消费预置报告，并触发真实写入事件；消耗当前账号额度，非 GUI 或审计质量测试。
- `node scripts/smoke-real.mjs`：可选，使用当前 Codex 账号和模型额度，在临时仓库检查受控缺陷。
- `node scripts/smoke-cli.mjs`：可选，使用已安装插件和当前账号，验证真实 CLI 的自动审计与下一条消息的模型消费；创建一个 CLI 测试会话，消耗正常额度。
- `npm run pack:release`：本地生成发布包与 SHA-256；不上传。个人实验记录 `docs/experiments/` 及 macOS `._` 元数据默认不进入 Git 或发布包。

同一份 22 场景脚本对照保留的实验前版本、第五轮版本、最终优化版，通过数为 0/22、16/22、22/22。这些场景专门复现已确认的缺陷，不是随机样本，不能推算模型准确率或整体质量百分比。详细个人实验记录保留在本机，未作为社区发布内容。五轮独立代码审计完成，但本实验 GUI 自动反馈链路未通过验收。
